# Assignment 1 — Fashion-MNIST Classification

This practical covers configuring TensorFlow/Keras, preprocessing and visualizing Fashion-MNIST images, and training a neural network to classify clothing categories.

## Files

- `DL_Assign1.ipynb` — notebook for loading the CSV data, reshaping and normalizing images, training the classifier, and evaluating predictions.
- `Assignment1.pdf` — practical report.
- `dataset/` — Fashion-MNIST CSV and IDX-format train/test data files.

## Requirements

TensorFlow/Keras, NumPy, pandas, and Matplotlib. The notebook reads `fashion-mnist_train.csv` and `fashion-mnist_test.csv` from the `dataset/` folder.

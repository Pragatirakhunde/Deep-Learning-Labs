# Assignment 3 — Forward and Backpropagation

This practical implements forward propagation and backpropagation with TensorFlow/Keras and studies how learning rates and training duration affect model performance. It uses the Breast Cancer Wisconsin dataset provided by scikit-learn.

## Files

- `assign3.ipynb` — notebook implementing the experiment and comparing training configurations.
- `Assignment3.pdf` — practical report.

## Requirements

TensorFlow, NumPy, pandas, and scikit-learn. The dataset is loaded from scikit-learn; no separate dataset file is needed.

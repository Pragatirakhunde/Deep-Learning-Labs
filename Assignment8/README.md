# Assignment 8 — BERT-Based Sentiment Analysis

This practical fine-tunes the pretrained `bert-base-uncased` model to classify IMDB movie reviews as positive or negative. It covers tokenization, training, evaluation, prediction on custom text, and saving model artifacts.

## Files

- `BERT_Sentiment_Analysis (1).ipynb` — notebook for fine-tuning and evaluating BERT on the IMDB dataset.
- `BERT_Sentiment_Analysis_file_output.pdf` — notebook output export.
- `BERT_Sentiment_model/` — saved model and tokenizer configuration artifacts.
- `Assignment8.pdf` — practical report.

## Requirements

PyTorch, Transformers, Datasets, Evaluate, Accelerate, scikit-learn, seaborn, NumPy, pandas, and Matplotlib. The notebook downloads the IMDB dataset and pretrained BERT assets, so internet access is needed; a GPU is recommended for faster training.

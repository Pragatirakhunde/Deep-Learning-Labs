# Assignment 2 — MLP Classification with Iris and Wine

This practical builds multilayer perceptrons (MLPs) for the Iris and Wine classification datasets. It demonstrates feature standardization, model training, and comparison of classification performance.

## Files

- `Assign2.ipynb` — notebook covering Iris and Wine MLP experiments and a model comparison.
- `DL_assign2.ipynb` — notebook focused on Iris classification.
- `Assignment2.pdf` — practical report.

## Requirements

TensorFlow/Keras, NumPy, pandas, Matplotlib, seaborn, and scikit-learn. The Iris and Wine datasets are loaded from scikit-learn, so separate dataset files are not needed.
